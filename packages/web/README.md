# `@repo-stitcher/web`

React dashboard served by `@repo-stitcher/cli` via its Elysia HTTP server. Vite-powered with Tailwind and Radix UI primitives.

## Status

Wave 0 scaffold. Real wizard and detail view land in Wave 1 (Epic 11, P-208 to P-237).

## Scripts

- `bun run dev` — Vite dev server (port 5173)
- `bun run build` — Vite production build to `dist/`
- `bun run preview` — Vite preview server
- `bun run typecheck` — TypeScript check (wired in P-002)
- `bun run lint` — ESLint (wired in P-003)
- `bun test` — Vitest (wired in P-004)
